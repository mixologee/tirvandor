# Shattered Oaths: Player's Guide

## Campaign Overview

### What is Shattered Oaths?
Shattered Oaths is an epic fantasy campaign about heroes rising to fight tyranny, fulfill an ancient prophecy, and potentially reshape the fate of nations. You play freedom fighters, chosen heroes, or those thrust into greatness, standing against the oppressive might of the Thaldros Empire and championing the cause of liberty.

**Core Themes:** ::
- Heroism and destiny
- Freedom vs. tyranny
- Ancient prophecy and fate
- Sacrifice and duty
- Hope in dark times
- Found family and bonds

**Campaign Tone:** ::
- Epic and inspirational
- Morally clear (mostly)
- Character-driven drama
- High stakes and importance
- Medium-high combat, high roleplay, medium exploration

## Who You Are

### The Chosen (Or the Thrust-Upon)
You are one of:

**The Idealist:** You believe in freedom and fight for it willingly ::
**The Reluctant Hero:** Circumstances forced you into this, but you'll see it through ::
**The Seeking Redemption:** Your past haunts you; this is your chance to be better ::
**The Destined:** Prophecy speaks of you (or so some believe) ::
**The Loyalist:** You fight for people/cause you love ::

**What Unites You:** ::
- Shared cause (freedom from tyranny)
- Belief that things can be better
- Willingness to sacrifice for others
- Opposition to Thaldros oppression
- Destiny (or the appearance thereof)

\column

## The Prophecy

### The Shattered Oath
An ancient prophecy, found in the Temple of Moira the Weaver:

{{descriptive

*When crowns grow heavy with the weight of chains,* ::
*When oaths are broken and freedom wanes,* ::
*Seven shall rise where seven once fell,* ::
*To break the cycle, to ring freedom's bell.* ::

*Warrior, Scholar, Healer, Rogue,* ::
*Mystic, Guardian, and Voice of the Folk,* ::
*United by purpose, divided by past,* ::
*The Shattered Oath mended at last.* ::

*When the Iron Crown cracks at last,* ::
*When the old order's chains are cast,* ::
*Seven souls shall light the way,* ::
*And freedom's dawn shall break the day.* ::

}}

:
**What This Means:** ::
- Some believe you're the "Seven" from the prophecy
- Thaldros fears this prophecy (they hunt "prophesied ones")
- Aethoria sees it as hope
- Whether it's real or self-fulfilling is up to you
- Prophecy gives you narrative importance but not invincibility

## Character Creation Guide

### Step 1: Choose Your Archetype
The prophecy mentions seven roles. Pick one that fits your concept:

**The Warrior** ::
"Strength in battle, courage in face of tyranny" ::
Classes: Fighter, Barbarian, Paladin, Ranger ::
Role: Front-line hero, defender ::
Theme: Martial prowess, protection ::

**The Scholar** ::
"Knowledge and wisdom light the path" ::
Classes: Wizard, Bard, Cleric, Artificer ::
Role: Lorekeeper, strategist ::
Theme: Intelligence, planning, history ::

**The Healer** ::
"Mercy and compassion in dark times" ::
Classes: Cleric, Druid, Bard, Paladin ::
Role: Support, hope-bringer ::
Theme: Healing, life, renewal ::

**The Rogue** ::
"Shadows and secrets, unseen blade" ::
Classes: Rogue, Ranger, Monk ::
Role: Scout, infiltrator, spy ::
Theme: Stealth, information, precision ::

**The Mystic** ::
"Power from beyond, magic unbound" ::
Classes: Sorcerer, Warlock, Wizard, Druid ::
Role: Raw magical power ::
Theme: Mystical might, otherworldly ::

**The Guardian** ::
"Shield for the weak, wall against evil" ::
Classes: Paladin, Fighter, Cleric, Monk ::
Role: Protector, defender ::
Theme: Duty, protection, sacrifice ::

**The Voice** ::
"Speaker for the voiceless, inspirer of hope" ::
Classes: Bard, Cleric, Paladin ::
Role: Leader, inspirer ::
Theme: Charisma, hope, unity ::

*Note: These are narrative roles, not mechanical requirements. Two Warriors are fine!*

### Step 2: Select Race
All races work, but consider these perspectives:

**Highly Thematic:** ::
Human - Most common in both nations, can be from anywhere ::
Half-Elf - Often caught between worlds, symbolizes unity ::
Tiefling - Persecuted in Thaldros, fighting back ::
Half-Orc - Seeking to prove worth beyond stereotypes ::

**Strong Choices:** ::
Elf - Ancient wisdom, connection to old magic ::
Dwarf - Stubborn resistance, ancestral strength ::
Dragonborn - Noble bearing, draconic destiny ::
Halfling - Underestimated heroes, common folk connection ::

**Interesting Options:** ::
Gnome - Clever innovation, unexpected heroes ::

#### Cultural Considerations:

**From Thaldros:** ::
Defector or escapee ::
Hunted by your former nation ::
Know the enemy intimately ::
Seeking redemption for past ::

**From Aethoria:** ::
Born to the cause ::
Revolutionary fervor ::
Deep belief in freedom ::
Community ties ::

\column

**From the Border:** ::
Neutral turned hero ::
Tired of the conflict ::
Wants better future ::
Outside perspective ::

### Step 3: Choose Class & Subclass

**Perfect for Shattered Oaths:** ::
Paladin - Oath of Liberty ::
- The heroic paladin for this campaign

Champion of freedom ::
- Breaks chains, inspires hope
- Designed specifically for Shattered Oaths

Barbarian - Path of Revolutionary Fury ::
- Righteous anger against tyranny
- Inspires resistance
- Breaks oppression with fury
- Designed for freedom fighters

Monk - Way of the Broken Chain ::
- Escaped slave or prisoner
- Master of liberation
- Frees the enslaved
- Perfect for anti-tyranny themes

Cleric - Ascended Champion ::
- Chosen of the Seven Ascended
- Divine hero
- Varied builds (7 options!)
- Ties to prophecy and gods

**Excellent Choices:** ::
Paladin - Oath of Devotion - Classic good paladin ::
Cleric - War Chaplain - Aethorian militiaman ::
Bard - Any college - Inspire and lead ::
Fighter - Champion - Heroic warrior ::
Ranger - People's Scout - Guerrilla freedom fighter ::
Wizard - School of Innovation - Aethorian mage ::
Sorcerer - Ascended-Touched - Touched by prophecy ::
Druid - Circle of the Ascended Wild - Nature's champion ::

**Good Choices:** ::
Most classes work with heroic concept: ::
- Fighters defending the weak
- Rogues stealing from tyrants
- Wizards seeking forbidden knowledge
- Warlocks with noble patrons

**Challenging (Requires Concept Work):** ::
Paladin - Oath of the Iron Crown - Thaldros loyalist (defector?) ::
Fighter - Royal Guard - Same issue ::
Rogue - State Inquisitor - Thaldros secret police (defector only) ::
Warlock - Evil patrons - Hard to be heroic ::

### Step 4: Background

**Tirvandor Custom Backgrounds** ::

These backgrounds are designed for Tirvandor. Full details in the PHB.

**Aethorian Revolutionary** ::
Born and raised to fight for freedom ::
Feature: *Revolutionary Network* - Resistance contacts everywhere ::
Skills: Persuasion, Stealth ::
Perfect for: Any class fighting tyranny ::

**War Refugee** ::
Lost everything to the conflict, now you fight back ::
Feature: *Sympathetic Ear* - Common folk help you ::
Skills: Survival, Stealth ::
Perfect for: Any class with tragic origin ::

**Temple Warden** ::
Guardian of sacred places of the Seven Ascended ::
Feature: *Temple Shelter* - Temples provide sanctuary ::
Skills: Religion, Athletics ::
Perfect for: Clerics, Paladins, Monks ::

**Political Exile** ::
Fled Thaldros after opposing tyranny ::
Feature: *Political Knowledge* - Understand how power works ::
Skills: History, Persuasion ::
Perfect for: Any class, especially former nobles ::

**Silver Circle Initiate** ::
Trained in ancient magical traditions ::
Feature: *Circle Hospitality* - Mages aid you ::
Skills: Arcana, History ::
Perfect for: Wizards, Sorcerers, Bards ::

**Worldrend Historian** ::
Scholar of ancient prophecies and the Worldrend ::
Feature: *Historical Expert* - Know ancient secrets ::
Skills: History, Investigation ::
Perfect for: Any class connected to the prophecy ::

**Thaldros Deserter** ::
Fled the Thaldros military, hunted by your former nation ::
Feature: *Military Training* - Know enemy tactics ::
Skills: Athletics, Survival ::
Perfect for: Fighters, Rangers seeking redemption ::

**Caravan Guard** ::
Professional escort turned freedom fighter ::
Feature: *Well-Traveled* - Know the roads and dangers ::
Skills: Perception, Survival ::
Perfect for: Fighters, Rangers, Monks ::

### Step 5: Your Call to Heroism
Why did you join this fight?

**Personal Reasons:** ::
Loss - Thaldros took someone you love ::
Injustice - You witnessed/experienced tyranny ::
Escape - You fled Thaldros oppression ::
Protection - Defending your community ::
Revenge - Against specific Thaldros agents (be careful) ::

**Idealistic Reasons:** ::
Belief - Freedom is worth fighting for ::
Destiny - You believe in the prophecy ::
Duty - Your gods/ancestors call you ::
Hope - You want a better world ::
Justice - Tyrants must be opposed ::

**Practical Reasons:** ::
Recruited - Aethoria resistance found you ::
Survival - Safest path forward ::
Skills - Your abilities are needed ::
Opportunity - Chance for something greater ::
Forced - Circumstances left no choice ::

**Mystical Reasons:** ::
Prophecy - You believe you're one of the Seven ::
Vision - Dreams/visions guide you ::
Divine Calling - The Ascended chose you ::
Magical Awakening - Power manifested in crisis ::
Ancestral - Continuing family destiny ::

## The Prophecy System (Optional)

### Fate Points
The DM may use Fate Points to represent destiny:

**Earning Fate Points:** ::
- Fulfill part of the prophecy
- Heroic sacrifice 
- Major victory against tyranny
- Inspire hope in others
- Achieve character arc milestone

**Spending Fate Points:** ::
- Reroll any d20 (after seeing result)
- Turn a death into a dramatic survival
- Have an NPC arrive at perfect moment
- Gain sudden insight or revelation
- Automatically succeed at crucial moment

**Starting Fate:** 1 point each ::

## The Resistance

### The Aethorian Freedom Movement
You're likely part of (or allied with) the Resistance:

**The Movement:** ::
- Decentralized network of cells
- United by opposition to Thaldros
- Mix of idealists, refugees, and fighters
- Supported by Aethoria government (covertly)
- Uses symbols: broken chain, rising sun

**Resistance Activities:** ::
- Freeing slaves and prisoners
- Sabotaging Thaldros operations
- Protecting refugees
- Gathering intelligence
- Spreading hope and propaganda

**Your Role:** ::
- Special operatives (you're heroes!)
- Handle big threats and opportunities
- Symbol for the cause
- Bridge between cells

## Campaign Structure

### What to Expect
Campaign Progression:

**Act 1: Spark (Levels 1-5)** ::
- Meet, form bonds, discover prophecy
- Small-scale resistance operations
- Build reputation as heroes
- Ends with: Major Thaldros threat/victory

**Act 2: Flame (Levels 6-10)** ::
- Larger operations, factional involvement
- Prophecy becomes known (you're hunted)
- Difficult choices and sacrifices
- Ends with: Major defeat or revelation

**Act 3: Inferno (Levels 11-15)** ::
- War comes to a head
- Face greatest Thaldros champions
- Fulfill or defy prophecy
- Ends with: Epic climax, fate of nations

**Typical Session:** ::
1. Downtime - Rest, bond, prepare (20 min)
2. New Information - Threats, opportunities, prophecy clues (20 min)
3. Planning - Decide approach, prepare (20 min)
4. The Mission - Heroic action! (1.5-2 hours)
5. Aftermath - Consequences, character moments (30 min)

**Combat Frequency: Medium-High** ::
- Meaningful battles, not constant
- Boss fights are epic
- Combat has narrative weight

**Roleplay Opportunities: High** ::
- Party dynamics and drama
- Moral dilemmas (but clearer than Blood & Coin)
- NPC relationships and romance
- Character growth and arcs

**Exploration: Medium** ::
- Discover ancient sites
- Explore prophetic locations
- Journey across Tirvandor

## Heroic Choices & Consequences

### You're the Good Guys (Mostly)

**Generally Good:** ::
- Fighting tyranny
- Freeing the oppressed
- Protecting innocents
- Inspiring hope
- Opposing evil

**Still Complex:** ::
- Collateral Damage - Your actions affect innocents
- Resources - Not everyone can be saved
- Methods - How far will you go?
- Allies - Some resistance members are questionable
- Personal Cost - How much will you sacrifice?

- Can you change fate?

## House Rules & Campaign Mechanics

### Special Rules for Shattered Oaths
**Heroic Inspiration** ::
- More frequent than normal
- For heroic acts and cool moments
- Can be stockpiled (max 3)
- Share with allies

**Bonds & Ideals** ::
- Your Bonds/Ideals matter mechanically
- Advantage when acting according to them
- Inspiration for great roleplay

**Death & Resurrection** ::
- Death is possible but rare
- Resurrection magic available (with cost)
- Heroic deaths may be permanent but meaningful
- Discuss with DM before character death

**Prophecy Moments** ::
- DM may invoke "prophecy moment"
- Dramatic scene where you shine
- Temporary power boost
- Story significance

**Hope System (Optional)** ::
- Track "Hope" as party resource
- Inspire NPCs with Hope
- Spend Hope for divine aid
- Lose Hope from defeats/betrayals

## Tips for Players

### How to Be a Hero

**In Combat:** ::
- Protect the weak
- Work as a team
- Dramatic moments over optimization
- Let everyone have spotlight
- Epic descriptions welcome

**Out of Combat:** ::
- Develop your character
- Build relationships with NPCs
- Engage with the prophecy
- Make hard choices in character
- Have personal goals beyond main plot

**Roleplay:** ::
- Have flaws and struggles
- Let others shine too
- Build party bonds
- Engage with moral questions
- Let character grow and change

**Don't:** ::
- Be edgy loner - You're heroes together
- Murder everyone - You're better than that
- Ignore prophecy entirely - It's central to campaign
- Hog spotlight - Share the heroism
- Betray the party - This isn't that campaign

## Frequently Asked Questions

**Q: Do I have to believe in the prophecy?** ::
A: No! Skeptical characters are valid. It's about the journey.

**Q: Can we lose?** ::
A: Yes, but not easily. Heroic stories have stakes.

**Q: What if my character dies?** ::
A: We'll discuss. Resurrection possible, or heroic sacrifice, or new character.

**Q: Can we be dark and edgy?** ::
A: Some darkness is fine, but remember the tone. You're heroes, not antiheroes.

**Q: Will romance be in the campaign?** ::
A: If you want! NPC romances are possible. Inter-party romance is up to you (communicate!).

**Q: Can I be from Thaldros?** ::
A: Yes! Defectors are great. You know the enemy intimately.

**Q: How powerful will we become?** ::
A: Very. By level 15, you're legendary heroes.

**Q: Is the prophecy railroading?** ::
A: No. It's a framework, not a script. You have choices.

**Q: What if we disagree on morality?** ::
A: Discuss in-character. Heroes can disagree and grow.

**Q: Can we change the world?** ::
A: That's the point! Your actions matter greatly.
